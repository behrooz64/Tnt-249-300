# Benelli TNT 249/300 Service Knowledge Base

هدف پروژه: تبدیل Service Manual خانواده TNT 249/300 به یک مرجع فارسی، قابل جست‌وجو و مناسب موبایل.

## منابع
- فایل اصلی کارخانه: `benelli-tnt300-service-manual-.pdf`
- ترجمه‌ها: `docs/fa/`
- داده‌های ساختاریافته: `data/`
- برنامه PWA: `pwa/`

## اصول
1. اطلاعات رسمی دفترچه از تجربه‌های تعمیر واقعی جدا نگه داشته می‌شود.
2. ترجمه‌ها بخش‌به‌بخش و با حفظ شماره صفحه، جدول، هشدار، اندازه و کد قطعه انجام می‌شوند.
3. تجربه کاربران ابتدا ساده ثبت می‌شود و قبل از نمایش عمومی نیاز به تأیید مدیر دارد.
4. نسخه اول روی جست‌وجوی سریع و استفاده موبایلی تمرکز دارد.
