156 
Control  
Handlebar Inspection  
 
Check: 
Handlebar (7). Fig. D. 
If there are bends / breakage / damage, please 
replace it. 
Warning 
If the handlebar is bent, do not try to bend it 
straight, because the handlebar will become weak 
and this increases the risk or breakage.
