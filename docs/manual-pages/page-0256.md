Intake Manifold 
Intake Manifold 
Installation of the intake manifold: 
● Apply grease on the sealing O-ring [A]. 
● Remember to install the sealing O-ring.  
● As shown in the figure, install the clamp [B].  
● Tighten the mounting bolts.  
Locking torque of the intake manifold mounting 
bolts: 12 N·m (1.0kgf·m, 106 in·lb)
