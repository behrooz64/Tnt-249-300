### مشخصات گیربکس و انتخاب بوش‌های یاتاقان
- ضخامت چنگال تعویض دنده: استاندارد **5.8–5.9 mm**؛ حد **5.65 mm**.
- عرض شیار چنگال روی چرخ‌دنده: **6–6.05 mm**؛ حد **6.15 mm**.
- قطر پین راهنمای چنگال: **7.93–8.0 mm**؛ حد **7.83 mm**.
- عرض شیار درام تعویض دنده: **8.05–8.15 mm**؛ حد **8.25 mm**.
- انتخاب بوش انتهای بزرگ شاتون بر اساس ترکیب علامت سوراخ شاتون و علامت قطر پین میل‌لنگ انجام می‌شود و رنگ‌های بوش **زرد/سبز/آبی** در جدول آمده‌اند.
- انتخاب بوش اصلی میل‌لنگ نیز بر اساس علامت سوراخ بوش اصلی **01/02/03** و علامت قطر مسیر اصلی **1/2** انجام می‌شود؛ رنگ‌ها **زرد/سبز/آبی/قرمز** هستند.
- شماره قطعه درج‌شده برای بوش انتهای بزرگ شاتون: **170116030000** و برای بوش اصلی میل‌لنگ: **150026030000**.
- چون جدول انتخاب بوش در OCR به‌صورت ستونی استخراج شده، برای تعیین یک بوش مشخص از روی علائم A/B یا 01/02/03 باید **تصویر اصلی همین صفحه** را ملاک نهایی قرار داد.
