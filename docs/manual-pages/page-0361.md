Fuel Pump 
 
Working Environment of the Fuel Pump 
● 
Fuel pump assembly shall be installed at the fuel tank bottom according to the installation 
requirements.  
● 
Generally, the fuel pump assembly design is only for gasoline fuel, ethanol and gasoline ratios 
of no more than 22% ethanol.      
● 
Please make sure that there is sufficient fuel when first running the fuel pump assembly. Don't 
run when there is no fuel as it can overheat and fail.  
●

### شرایط کار پمپ بنزین
- مجموعه پمپ در قسمت پایین باک نصب می‌شود.
- طبق دفترچه، طراحی مجموعه برای بنزین و سوخت حاوی اتانول تا **22٪** در نظر گرفته شده است.
- پمپ را بدون سوخت روشن نکنید؛ کمبود سوخت می‌تواند باعث داغ‌شدن و خرابی پمپ شود.
- مسیر اتصال شلنگ‌های سوخت شامل فیلتر، اتصال T و انژکتورهاست؛ مسیر دقیق طبق شکل همین صفحه بررسی شود.
- برای عیب‌یابی، سلامت شلنگ‌ها، فیلتر و اتصالات به‌اندازه خود پمپ اهمیت دارد.
