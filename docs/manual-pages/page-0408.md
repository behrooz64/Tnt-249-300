# Source page 408

 
407 
Starter Motor 
Starter Motor 
Starter motor assembly: 
Install the starter motor. Make sure to install dirt-proof 
boot properly.  
Attach the starter motor (1) onto the engine with the 
fixing bolts (2) as shown in Fig. A.  
Note: 
Tighten the two bolts to the following torque: 
 Torque: 7 ft·lb

## Persian notes

### نصب موتور استارت
- موتور استارت را روی موتور قرار دهید و **لاستیک محافظ گردوغبار** را صحیح نصب کنید.
- استارت با دو پیچ به موتور ثابت می‌شود.
- گشتاور دو پیچ: **7 ft·lb ≈ 9.5 N·m**.
- این مقدار از دفترچه TNT300 است و برای TNT249 باید با مشخصات مدل تطبیق داده شود.
