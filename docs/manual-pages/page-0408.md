# Source page 408

 
407 
Starter Motor 
Starter Motor 
Starter motor assembly: 
Install the starter motor. Make sure to install dirt-proof 
boot properly.  
Attach the starter motor (1) onto the engine with the 
fixing bolts (2) as shown in Fig. A.  
Note: 
Tighten the two bolts to the following torque: 
 Torque: 7 ft·lb

## Persian notes

### نصب موتور استارت
- استارت را روی موتور نصب کنید.
- لاستیک محافظ گردوغبار ترمینال را درست جا بزنید.
- دو پیچ اتصال استارت را ببندید.
- گشتاور اعلام‌شده دفترچه: **7 ft·lb ≈ 9.5 N·m**

این مقدار مربوط به دفترچه TNT300 است و برای TNT249 قبل از اعمال نهایی باید با مشخصات مدل تطبیق داده شود.
