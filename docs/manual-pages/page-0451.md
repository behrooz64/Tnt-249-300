# Source page 451

 
450 
Diagnosis breakdown of the Fuel Injection System 
Malfunction Detection Methods 
Use of the diagnostic apparatus for fault diagnosing 
 
 
Operation methods: 
a) 
6-wire diagnostic interface on motorcycle. 
b) 
Connect the cable and diagnostic instrument interface. 
c) Perform diagnosis after the ignition switch is turned to the on position. 
Warning 
● XCM－PT100X diagnostic apparatus is a highly sophisticated instrument which should be kept away from 
impact and vibrations;   
● If during the first start, the instrument doesn't work normally nor show stably. Please disconnect the power cord 
and retry; 
● Please make sure that connectors are always tight on the diagnosis interface; 
● It is strictly prohibited to use electrical signal exceeding the limiting value; 
● It is strictly prohibited for riders to use the instrument during driving process; 
● Use and storage conditions: 
Ambient temperature: 32 ~ 122°F 
Relative humidity: lower than 90%

## Persian notes

### استفاده از دستگاه دیاگ XCM-PT100X
روش اتصال طبق منبع:
1. رابط دیاگ 6 سیمه موتورسیکلت را پیدا کنید.
2. کابل را بین رابط موتورسیکلت و دستگاه دیاگ متصل کنید.
3. سوئیچ را روی حالت **ON** قرار دهید و سپس تشخیص را انجام دهید.

**هشدارهای سرویس:**
- دستگاه XCM-PT100X حساس است و باید از ضربه و لرزش دور نگه داشته شود.
- اگر هنگام اولین راه‌اندازی دستگاه پایدار نیست یا درست کار نمی‌کند، کابل برق را جدا کرده و دوباره متصل کنید.
- کانکتورهای رابط دیاگ باید کاملاً محکم باشند.
- اعمال سیگنال الکتریکی بیشتر از محدوده مجاز ممنوع است.
- استفاده از دستگاه توسط راکب هنگام حرکت ممنوع است.
- شرایط استفاده/نگهداری اعلام‌شده: دمای محیط **32 تا 122°F**، حدود **0 تا 50°C**، و رطوبت نسبی کمتر از 90%.
