### پارامترهای PCHUD، بخش دوم
ادامه متغیرهای نرم‌افزار:

| پارامتر | معنی |
|---|---|
| SAESTA | آوانس جرقه سیلندر 1 |
| SAIDLDYN | آوانس دینامیکی جرقه در دور آرام |
| SPDWELL | زمان Dwell کویل |
| IAINTEGOFST | انتگرال جریان هوای کنترل دور آرام |
| IACVDSMP | موقعیت هدف شیر کنترل هوای دور آرام |
| FCLCEN1 | فعال بودن اصلاح حلقه‌بسته سیلندر 1 |
| PPDSEBL | غیرفعال بودن پالس اولیه |
| FPENABL | فعال بودن پمپ سوخت |
| FTRNSAES | ورود به غنی‌سازی هنگام شتاب‌گیری |
| FTRNSDES | ورود به رقیق‌سازی هنگام کاهش شتاب |
| FTRNSAEDCLOAD | خروج از غنی‌سازی شتاب‌گیری |
| FTRNSDEINLOAD | خروج از رقیق‌سازی کاهش شتاب |
| FCLCEN2 | فعال بودن اصلاح حلقه‌بسته سیلندر 2 |

این نام‌ها عمدتاً برای مشاهده وضعیت داخلی ECU در نرم‌افزار PCHUD هستند و لزوماً به‌معنای قطعه قابل تنظیم توسط کاربر نیستند.
